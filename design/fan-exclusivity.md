## 1. 明確寫明「唔重複／唔再計」嘅規則

### 1.1 Raymond Ting 表明文例子

| 大／特殊 | 唔再計（細／重疊） | 原因 |
| --- | --- | --- |
| **缺一門** | **無字** | 缺一門定義已係「唔計番子而缺一門數牌」，同「無字」重疊 |
| **半求人** | **自摸** | 半求人本身就係全落地＋自摸單釣 |
| **海底撈月** | **自摸** | 海底必然自摸 |
| **叮摸** | **自摸** | 叮摸＝已叮兼自摸 |
| **天胡** | **自摸** | 天胡必然自摸 |
| **十六不搭** | **門清**、**五門齊**、**七門齊** | 門清型特殊牌；散張易齊五／七門，唔另加 |
| **五暗坎** | （偏高檔**另計**對對糊） | 片例五暗坎＋對對並存 |

同表另寫：**四同順／五同順** → **唔再計** 三相逢、一般高、兩般高、三般高（見下）。

### 1.2 同順「樓梯／同數順」類（坊間常見枱表）

| 大牌型 | 唔再計 | 備註 |
| --- | --- | --- |
| **明／暗五同順**（40／80） | 可另計般高／相逢（預設）；`excludeBanGaoXiangFengAfterWuTong: true` 時吞 | 明暗跟般高一樣：組成順全暗＝暗 |
| **明／暗四同順**（20／40） | 同上 | 同上 |

**歧義（一定要開枱講定）：**

- **香港麻雀協會 2025**：五同順 **60**、四同順 **20**，並寫明**必然另加**入面嘅般高、相逢。
- 舊坊間／Ting：計四五同順後唔再計般高相逢 → 開 `excludeBanGaoXiangFengAfterWuTong: true`。
- 本專案預設跟協會「另加」：`excludeBanGaoXiangFengAfterWuTong: false`。

### 1.3 明／暗只計一档

同一牌型有明／暗兩種番數時（般高、清龍、相逢、步步高等），**只計其中一個**（通常取暗＝更高，或按實際有冇上碰）。

## 2. 階層互斥：同類只取最高（大包細）

呢啲係「同一條梯子」，有大就唔再留細。

### 2.1 花／字組合

| 階（高→低） | 說明 |
| --- | --- |
| **無字花大平**（20） | 已含無字＋無花＋平胡 → 唔再計無字花／無字／無花／平胡 |
| **無字花**（10） | 唔再分開計無字＋無花 |
| **無字**／**無花** | 可並存（一邊有一邊無時） |

### 2.2 平胡系

| 階 | 唔再計 |
| --- | --- |
| **無字花大平** | 平胡、（通常亦唔再拆無字／無花） |
| **大鴨**（平胡型全帶么，20） | **平胡**（大鴨定義已係平胡型） |
| **平胡** | — |

> 「樓梯」若指**步步高／天梯**類大牌型：計咗大步高／天梯後，通常唔再重複計入面細嘅相連順組件；實際以番表單項為準。平胡系則係「全順無刻」一條線。

### 2.3 門清系

## 3. 「組合番」吞掉組件（必然包含）

| 組合番 | 通常吞掉 |
| --- | --- |
| 無字花大平 | 平胡、無字、無花、無字花 |
| 無字花 | 無字＋無花 |
| 門清叮／門清一摸八 | 對應門清五、（叮） |
| 機機糊 | 對對糊（＋門清自摸條件） |
| 大鴨 | 平胡 |
| 七門齊 | 五門齊 |
| 清一色 | 混一色 |
| 大三元／大四喜等 | 對應「小」版 |

**通常仍另計（唔算被吞）：**

- 底、莊／連莊
- 每組風牌／三元牌 2 番（大三元／四喜之後仍加——常見寫法）
- 每個明槓／暗槓
- 正花／爛花（按隻計）
- 叮（若未用門清叮档）
- 自摸（除非半求人／海底等明文唔加）

## 4. 協會「單式結算」（面子唔好重複搾乾）

麻雀數簿轉述協會原則：兩個牌型**共用嘅面子唔可以超過一半**。  
例：兩組四五六萬＋兩組四五六筒 → 只可以 **雙般高＋兩個相逢**，唔可以當四個相逢。  
呢條係「計法約束」，唔單止係番種名稱互斥。

| 應處理 | 現況風險 |

## 6. 實作建議（之後改 code 用）

1. 維持「階層組取 max」＋「組合番出現就 block 組件 id」。  
2. 補：**qimenqi > wumenqi**；求人；門清档；海底／半求人 vs 自摸；十六不搭 vs 門清；缺一門 vs 無字（若跟 Ting）。  
3. 四五同順繼續用枱規開關對協會／坊間兩套。  
4. 每個互斥組加單測：大牌出現時細牌 id 必須 absent。
