# 準確率 v1（規則向）

HK ToiMa **無牌譜引擎**；準確率唔係「最佳著」比對，而係可觀察規則事件嘅合成指標。

## 組成（有足夠樣本先計入）

| 權重 | 指標 | 最少樣本 |
|------|------|----------|
| 0.35 | 可糊把握率（出現可糊時有糊） | 可糊機會 ≥ 2 |
| 0.25 | 鳴牌把握率（碰／上／槓合計） | 機會 ≥ 3 |
| 0.25 | 少出銃（1 − 出銃／(食糊+出銃)） | 食糊+出銃 ≥ 3 |
| 0.15 | 練習提示跟從率 | 有提示棄牌 ≥ 3 |

實際權重會按**有數據嘅項**重新歸一。全部唔夠樣本 → 顯示「—」。

## 非目標（v1 唔做）

- 按巡／早中晚準確率（→ S7）
- 引擎「最佳棄」評級
- 同段位匿名基準線（需後端）

## 解讀

高分 ≈ 少漏糊、肯合理鳴、少出銃、練習時跟提示。唔等於牌力絕對值；篩選玩法／日期後先有意義。
